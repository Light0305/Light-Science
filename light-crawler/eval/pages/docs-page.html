Rate Limiting

Each API token may make at most 600 requests per minute. The limit is enforced per token, not per account, so splitting work across tokens owned by the same account does not raise the ceiling.

When the limit is exceeded the API returns HTTP 429 with a Retry-After header that states how many seconds the client must wait before the next request.

Every response carries the X-RateLimit-Remaining header, and well-behaved clients should slow down when the remaining count drops below ten percent of the quota.

curl -H "Authorization: Bearer TOKEN" https://api.example.com/v1/jobs

Burst allowance: a token may exceed the per-minute rate for at most five consecutive seconds, after which the standard enforcement applies without warning.
