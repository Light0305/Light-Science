# light-patent 评测集（Q10）

- 构成：`cases.jsonl` 12 个已结案式封闭案例 + `reference_answers.jsonl`
  参考答案 + `run_eval.py` 确定性评分器。
- 形态来源（只借形态，不复制任何外部数据）：IPBench 的 DOK 四级
  认知分层（L1 信息处理 / L2 逻辑推理 / L3 判别评价 / L4 创造
  生成）；patent-bench 的真值形态（判定点锚定客观依据——法条与
  审查指南原文，而非自标相关度）。IPBench 无许可证、patent-bench
  子集为 CC BY-NC，本集数据全部自建脱敏，不含其任何条目。
- 分布：L1 三例（宽限情形、发明人资格、附加费项数）、L2 三例
  （公开阻断、第 33 条、不确定词）、L3 四例（D1 选择、渠道失败
  分型、比特流客体、第 5 条伦理）、L4 二例（AI 充分公开、贡献
  特征入权要）。
- 用法：模型/技能版本变更后，用同一批案例作答（答案形态：
  `{case_id, decision, points}` 的 jsonl），跑
  `python run_eval.py --answers <答案文件>`；全过才算不回退。
  参考答案应得 12/12，评分器对注错答案判败有测试钉住
  （tests/test_eval.py）。
- 边界：本集测的是口径与决策点，不是端到端撰写质量；撰写质量
  由 P4 检查器、红队与盲评规程承担，不许用本集分数冒充全包质量。
