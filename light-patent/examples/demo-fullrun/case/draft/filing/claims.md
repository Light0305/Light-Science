# 权利要求书（工作副本）

发明名称：一种基于时序融合的家禽异常行为检测方法

1. 一种家禽异常行为检测方法，包括：获取舍内监控视频流并按固定帧间隔抽取视频帧序列；将视频帧序列输入时序融合检测模型得到每只家禽个体的行为特征向量，其中时序融合检测模型包含空间特征提取模块与时序聚合模块；根据行为特征向量与个体基线行为分布之间的偏差量计算异常分数；当异常分数超过自适应阈值时输出异常行为报警信息，其中自适应阈值由个体基线行为分布的统计量确定。

2. 根据权利要求1所述的家禽异常行为检测方法，其特征在于：时序融合检测模型中的时序聚合模块采用滑动窗口注意力对视频帧序列进行加权聚合。

3. 一种家禽异常行为检测装置，包括：视频采集单元，用于获取舍内监控视频流并按固定帧间隔抽取视频帧序列；处理单元，用于运行权利要求1所述方法中的时序融合检测模型并输出异常行为报警信息。

4. 一种计算机可读存储介质，其上存储有计算机程序，该程序被处理器执行时实现权利要求1所述的方法步骤。
