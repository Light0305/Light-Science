# light-patent 演示报告（demo-fullrun）

- 案例：火鸡行为检测主线的一项未公开改进方案（时序融合 + 个体
  基线偏差），材料全部自造脱敏；团队已发表的基础论文
  （Zhang et al., Computers and Electronics in Agriculture 239
  (2025) 110856）作为最接近现有技术 D1 如实入池。
- 驱动：`run_demo.py`，离线可整删重跑；产物在 `case/`。
- 终点状态：**responded**（含模拟递交与模拟审查意见，均已标注
  「演示模拟」，不与真实收据混同）。

## 走通的主链（15 步留痕）

1. init 建案（AI 类标记）→ P0 审计：改进方案无在先公开，具名
   确认后结论 clear；同时落伦理审查登记（数据采集面，舍内动物
   数据不含个人信息）。
2. P1：scan-code 盘点演示代码仓 2 个文件（C001/C002）；源图谱
   登记 P/E/F 与口头交底锚点；候选表三案，选最强 CAND-1
   （拼接跟踪降后备、报警分级并入从属特征）。
3. P2：两轮召回登记；先试锁未核验条目 CN119000111A，被以
   LP-01 点名拒绝；改锁已发表基础论文为 D1（全文级），区别
   特征 F1（时序融合）、F2（个体基线偏差），三态门
   pass_with_doubts。
4. P3/P4：权要 v1 在权要 2 故意植入不确定词「优选」，检查器
   C-03 咬住（1 ERROR，等级 incomplete_draft）；修正后重登记，
   strip 剥离申报副本三件洁净，红队两队落账，复检 0 ERROR
   （3 WARN 为先行基础启发式，待人工复核），等级
   deliverable_draft。
5. P6：worth-it = file_narrowed（附三项证据账）；登记模拟递交，
   台账算出请求实审期限。
6. P5：登记模拟审查意见 OA-1（创造性缺陷，引证 D1）；修改
   AM-1 把从属权要 2 的时序聚合特征并入独权，出处指针为原
   权利要求 2 并附原文摘录（第 33 条）；导出会稿问题清单
   （1 条缺陷 + 1 项缺口）。
7. validate 全包 ok，errors 为空。

## X-10 交付收尾四行

- 完成项：主链 P0–P6 全部走通；四处纪律咬合实证（未核验拒锁
  D1、不确定词被咬、剥离洁净、第 33 条出处齐备）；validate ok。
- 跳过项：真实渠道检索（演示用登记式留痕，未访问任何外部站点）；
  CAND-2/CAND-3 未成案（按默认一案口径）。
- 未验项：先行基础 3 条 WARN 未做人工复核结论；创造性终局判断
  按分级声明留代理师复核，本演示不给结论。
- 风险：D1 为团队自有已发表论文，真实案件中自有在先公开的
  处置须经代理师确认；演示申请号与审查意见均为模拟件。
