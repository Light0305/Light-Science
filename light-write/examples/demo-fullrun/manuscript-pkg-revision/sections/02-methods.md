# Methods

The preregistered analysis plan for this study was fixed before any outcome data were examined, and the same frozen plan was applied to every arm. The study compares three arms of one tracking pipeline. In the fixed-threshold arm, thresholds keep the values carried over from earlier work. In the oracle arm, thresholds are set with knowledge of the held-out outcomes and serve as an upper reference. In the predicted-threshold arm, thresholds are predicted from video-level statistics computed before tracking begins.

Attention modules have been combined with encoder-decoder segmentation networks in earlier video-analysis pipelines [@bai2021-enet], and the segmentation stage of the present pipeline follows that general design. The pipeline itself, its configuration, and the derivation of thresholds from video-level statistics are described in the synthetic execution package that accompanies this study.

The independent experimental unit is the held-out segment [rev:RC002]: a contiguous recording that was excluded from all threshold tuning and configuration choices before the runs began. Each arm was run on the same set of held-out segments, with repeated seeds inside a segment averaged before any comparison, so that no segment contributes more than one value per arm. A claim-to-analysis mapping is maintained for the study: each registered claim is linked to the comparison, the replication unit, and the analysis lines that bear on it, and any field that the analysis does not supply is marked as author input needed rather than filled in by assumption. All thresholds, configurations, and segment assignments were frozen before the runs, and deviations from the frozen configuration are recorded in the execution package rather than absorbed silently.
